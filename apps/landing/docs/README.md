# Landing (`apps/landing`) — documentation index

Next.js 15 App Router marketing site for **IQ Rest** at `iq-rest.com`. 35 locales,
almost fully statically generated, plus the first-party auth pages (login /
register) and the in-product help guide.

This folder is the detailed reference for the landing. The repo-level
[`../../CLAUDE.md`](../../CLAUDE.md) keeps only a short summary and links here.

## Files

| File | What it covers |
|------|----------------|
| [`architecture.md`](./architecture.md) | App Router structure, every route/page, route groups, the `_landing/` engine (templates + blocks), auth pages, demo iframes, help guide. |
| [`i18n.md`](./i18n.md) | The custom (post-next-intl) translation system: 35 locales, colocated JSON messages, chrome context, per-locale SEO slugs, the i18n scripts, and the add-a-key / add-a-locale workflow. |
| [`seo-and-infra.md`](./seo-and-infra.md) | `next.config.ts` 301 table, `middleware.ts`, the `lib/` plumbing, analytics event pipeline, sitemap/robots/hreflang, build & deploy specifics. |

## ‼️ Keep these docs current

**After every change to the landing — a new feature, a reworked block, a bugfix,
a route/redirect/slug change, a new locale, an analytics tweak — update the
relevant file here in the same change.** These docs exist so work starts from a
current map instead of re-reading the whole app each time; a stale doc is worse
than none. Prefer a small precise edit near the affected section over a full
rewrite, and keep the repo-level `CLAUDE.md` landing summary in sync when a
high-level fact changes.

## Fast facts

- **Local dev:** part of the monorepo — `cd iq-rest && ./scripts/dev.sh`; landing
  on `http://localhost:8001`.
- **Prod:** `next start -p 8123`, pm2 process `iq-rest`, host `iq-rest.com`.
  Deploy: `gh workflow run deploy.yml -f service=landing`.
- **Package name: `iq-rest-landing`** (renamed from legacy `soqrmenuweb` 2026-08-15).
- **Gate before hand-off:** `npm run typecheck` (repo-wide `lint` is broken —
  pre-existing ESLint v9 issue). Never self-test; the owner tests and deploys.
- **Translations are hand-written**, not generated by the Gemini script — see
  [`i18n.md`](./i18n.md).
